# Translated D3D9 pixel shader proof

A consumer-authored `ps_1_1` shader now passes translation, SPIR-V compilation,
draw and readback on the physical Snapdragon 680 tablet with both Vulkan drivers.
This extends the [generic Vulkan draw proof](vulkan-draw-2026-11-01.md).
It does not establish full D3D9 or game rendering.

| Measurement | Stock Qualcomm | App-private Turnip |
| --- | --- | --- |
| Vulkan API | 1.1.128 | 1.3.352 |
| Reported device extensions | 70 | 140 |
| Generic red draw/readback | 16/16 pixels | 16/16 pixels |
| D3D9 pixel shader translated and compiled | Yes | Yes |
| Translated green draw/readback | 16/16 pixels | 16/16 pixels |
| Translated shader draw/readback elapsed | 25 ms | 14 ms |

Times are single diagnostic measurements, not game frame times. Device:
Xiaomi 23073RPBFG / SM6225, Android 15 / API 35, Adreno 610.

## Executed path

The fixture defines a green constant and moves it to the pixel output. The
pinned kit's `d9sh::program_for` parses the D3D9 bytecode and
`d9glsl::pixel_source` generates GLSL. glslang compiles that output on Android
for Vulkan 1.1 / SPIR-V 1.3. An independently authored fullscreen vertex shader
provides the expected varyings. The test binds the generated pixel constants
and 48-byte std140 parameter block, draws a triangle into a 4x4 image, copies
it to host-visible memory, and compares every pixel with `[0,255,0,255]`.
Noncoherent uniform writes are flushed; noncoherent readbacks are invalidated.

The draw uses the selected loader's entry points, instance, device and queue.
Stock and Turnip run in separate processes; their reported driver identities
differ. The invalid `../outside.so` driver name is still rejected before loading.
No system driver or global Android graphics setting was changed.

Reports distinguish `d3d9_ps_translation_compiled` from
`d3d9_ps_draw_verified`. The host verifier rejects compilation without complete
pixel evidence, and `--require-d3d9` rejects APKs built without this optional
feature. All 41 tooling tests pass, including these negative cases.

This fixture covers pixel-shader DEF/MOV and the generated parameter interface.
Guest D3D9 COM calls, translated game vertex shaders, textures, Cg, original
draw packets, swapchain presentation and a game content frame remain pending.
The report retains `d3d9_verified:false` and
`dxvk_compatibility_verified:false`.

## Reproduce

```powershell
$env:RECOMP_KIT_ROOT = '<clean pinned recomp-kit checkout>'
.\gradlew.bat -p native-runtime/android assembleDebug --no-daemon --max-workers=1
python native-runtime/tools/test_vulkan_driver.py --apk native-runtime/android/app/build/outputs/apk/debug/app-debug.apk --driver app/src/main/assets/graphics_driver/adrenotools-turnip26.2.0.tzst --output native-runtime/.work/vulkan-d3d9-results.json --require-d3d9
```

`-PrecompKitRoot=<path>` also enables the proof. Without a kit path, the APK
continues to build the generic Vulkan probe. CI supplies the pinned checkout
and compiles the shader-enabled APK; physical device results are separate.
